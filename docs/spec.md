# 产品与系统规格

状态：Active

## 1. 产品定义

当前产品名称为“拉了么”，仓库和包名中也使用 `Poopornot`、`WhereToPoop`。早期曾考虑“去哪儿啦”，当前界面和微信配置均以“拉了么”为准。

产品目标：让用户以当前位置或手动选定地点为基准，快速查找附近公共厕所；同时展示附近地铁站以及该站厕所状态，并把用户交给合适的路线或导航能力。

## 2. 目标用户与核心场景

- 出行途中需要立即找到附近公共厕所的用户。
- 定位不准确、拒绝定位或希望提前查询其他城市的用户。
- 希望知道附近地铁站是否有厕所的用户。

核心场景：

1. 打开客户端并授权定位。
2. 以当前位置为基准查看厕所结果。
3. 调整搜索半径，或切换城市并选择具体地点。
4. 查看厕所或地铁站详情。
5. 发起路线或外部导航。

## 3. 通用业务规则

### 3.1 查询基准点

- 基准点优先来自用户当前定位。
- 用户可以选择城市，再搜索小区、商场、地铁站或地址作为新基准点。
- 网页和微信小程序均可通过地图右键/长按并确认“选这里”建立新查询中心。
- 搜索地点候选使用普通地点标记，不得伪装成厕所标记。
- 城市中心仅用于用户主动切换城市后的初始视图，不应覆盖成功获得的当前位置。

### 3.2 厕所搜索

- 客户端支持 300 m、500 m、1 km、3 km 四档常用半径。
- 客户端调用 `/api/toilets`，当前默认请求上限为 100。
- 结果显示名称、地址和距离；地图标记与列表项必须指向同一 POI 坐标。
- “指定半径内所有厕所”是产品意图，不是数据完备性承诺。国内受高德覆盖与配额影响；小程序海外受 OSM/Geoapify 覆盖、公共服务可用性和结果上限影响。

### 3.3 地铁站厕所状态

- 地铁专用入口查询基准点 20 km 内地铁站，不只按行政城市归属筛选。
- 客户端提供最近 10 个地铁站列表。
- 状态 `1` 显示绿色、`0` 显示红色、`2` 显示橙色。
- 线路颜色来自共享 JSON；客户端不连接站点绘制线路。
- 国内未匹配人工状态和全部海外站点默认为 `2`。

### 3.4 导航

- 网页：国内展示后端高德步行路线；海外使用原始 WGS84 打开外部 Google Maps。
- 微信小程序：只保留“导航”，调用 `wx.openLocation`，不在小程序内部绘制路线。
- Android：当前同时保留后端步行路线和外部地图导航。

## 4. 平台规格

### 4.1 网页

当前有效：

- 中国大陆使用高德 JS API 2.0/GCJ-02，海外使用同源 Leaflet 1.9.4、Geoapify Tiles/WGS84。
- 浏览器定位成功后显示实际城市、建立查询中心并自动搜索默认 1 km 厕所，不自动查询地铁。
- 国内城市文本切换、海外六城下拉、地点关键词搜索、候选选择和地图右键/长按选点。
- 城市切换只移动视口并清空查询中心；文字地点和地图选点采用两步查询。
- 默认厕所半径 1 km；已有中心时切换半径立即刷新厕所。
- 地铁只由专用按钮查询 20 km 内最近 10 站，厕所与地铁 marker 相互保留。
- 左侧结果抽屉、滚动列表、地图标记和详情。
- 国内厕所与地铁站绘制高德步行路线；海外打开 Google Maps 外部导航。
- 高德地图样式与 Geoapify 明暗瓦片跟随主题，主题保存到 `localStorage`。

发布前未完成项见 `docs/specs/web-global-support/acceptance.md`，主要包括真实浏览器定位、移动端长按、外部导航弹窗和六城完整 UI 矩阵。

### 4.2 微信小程序

当前有效：

- 启动时请求 WGS84 定位并识别国家；国内再获取 GCJ-02，海外保持 WGS84。定位成功后自动搜索默认 500 m 内厕所，不加载地铁。
- 定位失败时打开城市选择面板。
- 中国大陆推荐城市/字母索引，以及六座海外重点城市快捷入口。
- 城市切换只移动视口并清空查询中心；文字地点和地图长按确认只建立查询中心，等待“查厕所”。
- 已有查询中心时半径切换立即重新查询厕所，同时保留“查厕所”按钮；没有中心时只提示。
- 地图右上角定位、地铁和昼夜切换按钮。
- 地铁按钮才发起 20 km 最近 10 站查询；厕所和地铁 marker 相互保留，结果均只有“导航”。
- `wx.openLocation` 打开微信位置页。
- 分享给好友/群聊和朋友圈。
- `UpdateManager` 检测新版本、提示重启和下载失败。
- UI 深浅色切换；当前微信地图保持原生默认底图，个性化深浅底图尚未重新接入。

当前不再存在小程序“路线”按钮、路线结果页、折线绘制或 `/api/navigation` 调用。

### 4.3 Android

当前有效：

- 高德地图和一次性高精度定位；定位成功后逆地理编码城市、加载地铁并自动搜索 500 m 内厕所。
- 定位权限拒绝时引导选择城市和地点。
- 推荐城市、字母索引、地点搜索和基准点选择。
- 300 m、500 m、1 km、3 km 半径选择；当前半径变化本身不自动搜索，用户点击查询按钮。
- 最近 10 个地铁站、厕所状态标记和结果详情。
- 后端步行路线折线与摘要。
- 高德外部导航，未安装高德时使用系统 `geo:` Intent。
- Android 深浅色主题和高德日/夜地图类型。

## 5. 数据与外部服务

- 国内厕所、地点、逆地理编码、地铁坐标和步行路线依赖高德 Web Service。
- 小程序海外识别、文字地点、厕所和地铁均依赖 Geoapify；国内定位反查与查询继续使用高德。
- 网页国内地图依赖高德 JS API；海外地图依赖同源 Leaflet 1.9.4 和浏览器直连 Geoapify Tiles。
- 小程序地图依赖微信 `map` 组件及腾讯位置服务配置。
- Android 地图和定位依赖高德 Android SDK。
- 国内地铁厕所状态来自 `data/metro`，当前不包含坐标；海外状态第一版统一为 `2`。

## 6. 非功能要求

### 6.1 可用性

- 定位失败时必须允许手动选择城市和地点。
- API 错误应显示可理解的信息，不能导致后端进程退出。
- 厕所查询遇到高德限流且已获得部分结果时，应返回已有结果并标记 `partial`。

### 6.2 性能

- 国内地铁只在按钮点击后进行一次周边查询并匹配本地状态，不允许恢复逐站、逐城扫描或启动预加载。
- 海外供应商请求必须有超时、错误恢复、排序和厕所 100 / 地铁 10 的数量上限。
- 结果列表必须可滚动，不应因结果数量撑出视口。
- 外部 API 分页请求应保留间隔，避免短时间触发 QPS 限制。

### 6.3 安全与隐私

- `AMAP_WEB_SERVICE_KEY` 只能保存在后端。
- `GEOAPIFY_API_KEY` 只能保存在后端。
- 正式小程序 API 必须使用 HTTPS 合法域名。
- 定位只用于当前查询与导航，不进行后台持续定位。
- 当前不保存用户位置、搜索历史或账号信息。

### 6.4 兼容性

- 小程序代码避免使用目标微信编译链不支持的语法；历史上 `??` 与可选链曾导致预览失败。
- Android 最低 API 24，构建使用 JDK 17。

## 7. 状态分类

### 当前有效

- 三端客户端、统一后端、共享地铁状态数据。
- 当前位置、文字地点以及网页/小程序地图选点查询中心。
- 附近厕所和 20 km 附近地铁站查询。
- 小程序外部导航，网页国内和 Android 内部步行路线，网页海外外部导航。
- 网页和小程序海外 WGS84 厕所、地铁与六城文字搜索。

### 曾经实现但已移除

- 小程序内部路线按钮与 `/api/navigation`。
- 地铁线路直线连接和 JSON 内坐标。
- 后端逐个站点查询坐标。
- 小程序启动和查询中心变化时自动预加载地铁。
- 国内地铁活动链路逐城分页建立完整坐标索引。
- 不确定状态使用灰色。

### 尚未实现

- 地铁厕所状态投票、纠错、补点和临时关闭。
- 全国城市完整人工地铁线路与厕所核验。
- 自建厕所 POI 数据库、搜索缓存、后台管理和账号体系。
- CI、监控、告警和配额仪表盘。
- Android 海外支持和全球任意城市文字搜索列表。

### 已放弃

- 当前阶段自建完整全国厕所数据库。
- 在地图底图已经提供真实线路时，由客户端用直线重画线路。

### 无法确认

- Android 是否计划正式发布，还是当前仅作为技术验证客户端。
- “路线只保留外部导航”的决策是否未来也会扩展到 Android。
- 当前微信小程序线上版本号、审核状态和实际用户规模。

## 8. 验收标准

### 通用

- 成功定位时，基准点是实际定位坐标，不是默认城市中心。
- 城市切换不建立基准点；文字地点或地图“选这里”确认后，厕所和地铁距离以新查询中心计算。
- 厕所标记、列表、详情和导航目标坐标一致。
- 城市边界附近能显示半径内其他城市地铁站。

### 微信小程序

- 首次进入并授权定位后，自动出现默认半径厕所结果。
- 选择半径后自动查询；“查厕所”按钮仍可重复查询。
- 地铁只由专用按钮查询，且不清除厕所 marker。
- 国内 marker/导航使用 GCJ-02，海外使用同一原始 WGS84。
- 厕所和地铁结果只显示“导航”，不存在“路线”。
- 正式域名校验开启时 API 请求成功。

### 网页

- `/api/config` 配置正确时高德地图可加载。
- 厕所和地铁标记点击后出现详情；国内显示路线入口，海外显示导航入口。
- 深浅色切换同时更新 UI、国内高德样式与海外 Geoapify 瓦片。
- 网页全球支持的发布门禁以 `docs/specs/web-global-support/acceptance.md` 为准；未勾选的真机/真实浏览器项目不得宣称已通过。

### Android

- 定位授权、拒绝授权和手动城市三条路径均可继续使用。
- 后端路线与外部地图导航目标一致。
- 深浅色主题下状态色可辨识。

## 9. 待确认
