# 安全与隐私

状态：Active

本文描述当前代码边界，不替代法律审查、微信平台申报或第三方服务条款。

## 1. 位置数据流

当前位置和用户选点用于地图展示、国家/城市识别、附近厕所/地铁、距离和导航。当前没有业务数据库，也不持久化位置、搜索历史、查询中心或导航记录。

第三方处理路径：

| 场景 | 第三方 |
| --- | --- |
| 网页地图与国内业务 | 高德 JS API / Web Service |
| 小程序底图与位置页 | 微信 `map` / 腾讯地图、`wx.openLocation` |
| 小程序全球国家/城市识别 | 后端转发至 Geoapify Reverse Geocoding |
| 小程序海外文字地点 | 后端转发至 Geoapify Forward Geocoding |
| 小程序海外厕所/地铁 | 后端转发至 Geoapify Places |
| Android 地图与定位 | 高德 Android SDK；业务经统一后端 |

“本项目不持久化”不等于第三方不处理。正式隐私文本必须列出实际处理者、用途和平台政策链接，法务措辞待确认。

## 2. 权限与触发

### 2.1 微信小程序

`WhereToPoop/miniprogram/app.json` 声明 `scope.userLocation` 和 `requiredPrivateInfos: ["getLocation"]`。页面首次挂载会自动请求一次 WGS84 定位；用户点击定位按钮时再次请求。中国大陆识别成功后会再获取一次 GCJ-02 坐标，但不进行后台持续定位。

用途说明应覆盖：显示当前位置、识别所在国家/城市、自动查询附近厕所、按按钮查询附近地铁和导航。若用户拒绝，可继续选城市、搜索地点或长按地图。

### 2.2 Android

Android 声明网络、Wi-Fi 状态和粗略/精确位置权限，采用一次性高精度定位。`CHANGE_WIFI_STATE` 与 `allowBackup=true` 是否必要仍待发布前最小权限复核。

## 3. 密钥管理

| 密钥 | 位置 | 暴露模型 | 限制 |
| --- | --- | --- | --- |
| `AMAP_WEB_SERVICE_KEY` | 后端 `.env` | 仅服务器 | 服务白名单、配额和轮换 |
| `GEOAPIFY_API_KEY` | 后端 `.env` | 仅服务器 | 项目配额、来源限制和轮换 |
| `AMAP_JS_KEY` / security code | 后端 `.env`，经 `/api/config` 到网页 | 浏览器可见 | 生产域名白名单 |
| `AMAP_ANDROID_KEY` | 构建配置并嵌入 APK | 可提取 | 包名和签名 SHA1 |
| 腾讯地图 subkey | 小程序包 | 可见 | 小程序 AppID/平台限制 |

当前措施：

- `.env` 被 Git 忽略；`.env.example` 只含空值和公共默认 URL。
- 小程序源码不包含 Geoapify Key。
- `/api/config` 只返回网页必须使用的 JS 配置。
- 供应商错误会脱敏已知密钥和 URL 中的 `apiKey`/`key` 参数。

历史上 `.env.example` 曾出现疑似真实高德 Key，是否已经在供应商控制台吊销仍无法从代码确认；应继续按可能泄露处理并核对 Git 历史。

## 4. 网络与 API 暴露

- 小程序生产基址是 `https://pp.nuanzhualife.cn`，必须具有有效证书并配置微信 `request` 合法域名。
- Node 可在内网监听 `5174`，由 Nginx/Caddy 终止 TLS。
- Android 受控 fallback 仍允许旧公网 HTTP，正式发布前应切换 HTTPS 并评估关闭明文流量。
- 后端 CORS 当前为 `*`，没有认证、限流或来源校验；公开部署后可能被第三方消耗高德/Geoapify配额。
- `server.js` 的静态文件路径有根目录检查，但安全响应头主要依赖反向代理。

## 5. 日志与保留

后端海外诊断记录请求类型、区域、供应商、耗时、结果数量、降级、截断、坐标系，以及四舍五入到 5 位小数的请求坐标。5 位小数仍可能定位到米级附近，不能视为匿名数据。

当前没有正式日志保留期、访问控制或反向代理查询字符串脱敏配置。生产要求：

- 不记录完整 API Key、第三方带 Key URL 或用户标识；
- 尽量不记录完整查询字符串；
- 对坐标日志设置最短必要保留期和访问权限；
- 检查 Android OkHttp、微信控制台和反向代理是否记录 URL 坐标。

## 6. 数据署名

海外页面当前显示“地点数据 © OpenStreetMap contributors · Geoapify”。正式发布前仍需按 OSM ODbL、Geoapify 当前条款和实际 UI 复核署名可见性、链接与措辞；代码中的当前文字不构成法律合规结论。

## 7. 当前边界

### 当前有效

- 无账号、无业务数据库、无后台持续定位、无轨迹持久化。
- API Key 仅按平台需要暴露，Geoapify 与高德 Web Service Key 只在后端。
- 海外坐标经自己的后端转发到 Geoapify。

### 尚未实现

- API 认证、服务器限流、配额告警、集中日志脱敏和正式保留策略。
- 用户投票、纠错、数据导出/删除流程和第三方清单自动化。

### 无法确认

- 线上反向代理、云平台和供应商的实际日志保留。
- 微信后台当前隐私保护指引文本与 Android 商店隐私政策。
- 历史疑似 Key 是否已在控制台全部吊销。
